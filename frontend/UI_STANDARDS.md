# OYS E-Library UI standards — Arctic Blue

## Non-negotiable visual constraints

- Palette: background `#F3F8FC`, primary `#3975A5`, ink `#233A50`, soft blue `#DCECF5`, white document surfaces.
- Keep page structure predictable: fixed desktop navigation, one search/filter zone per list, responsive reading surface, logical breadcrumbs, no empty decorative blocks.
- Use text labels and actual topic illustrations on material cards. Static SVG/PNG/WebP only. No GIF covers, autogenerated-floating graphics, emoji-as-icons, invented achievements, or pretend KPIs.
- Only sidebar navigation icon strokes may move, on `hover` or `focus-visible`, with ~180 ms transforms. Support `prefers-reduced-motion`.
- Translucency is a background treatment for chrome and light cards, never for the PDF reading surface, controls, or critical legibility.
- Mobile: menu toggle and dismiss overlay, all forms 1-column at narrow widths, no global horizontal clipping to hide overflow.
- Design all loading, empty, permission-denied, validation-error, processing, and publication-error states before calling screens complete.
- Always distinguish demo fixtures from production data. Never allow demo routes in production.

## Engineering quality gates before UI acceptance

1. `npm run lint`, `npm run typecheck`, and `npm run build` must pass with exact installed dependencies.
2. Run `python tests/browser_smoke.py` against a live dev preview at 360, 390, 768, 1280, 1440 px for Student, Reader and Admin, and resolve screenshots/overflow failures.
3. Test keyboard navigation, focus indicators, dialog focus return, sufficient contrast, reduced motion and real text zoom at 200%.
4. Verify every button has a user-visible effect or is explicitly disabled/unavailable. Do not simulate server state as if persisted.
5. Run backend tests and Flyway migrations against a disposable PostgreSQL instance; never test migration changes first on production data.
6. Perform authenticated authorization tests using real OYS claims, including unauthorized student→admin calls and cross-college catalogue access.
