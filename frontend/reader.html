CHAPTER 04

Variables & types

A variable stores a value that can be used by a program. In Java, each variable has a data type that describes the values it can hold.

Java provides primitive data types for simple values, and reference types for objects and arrays.

int age = 21;
String student = "OYS";
boolean ready = true;

Declare a variable by naming its type, then the variable, and optionally an initial value. The compiler uses type information to validate operations.
